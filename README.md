N'DIAMOI ANGAMANJULES CHRIST

**Présentation du projet**

Ce projet est une application en ligne de commande  pour  en JavaScript . Son objectif est d'automatiser la prise de commande et le calcul de caisse d'une petite cantine. L'application gère la sélection des plats, le calcul des totaux, et génère un ticket de caisse détaillé directement dans le terminal, tout en gérant la monnaie à rendre ou le montant manquant.

**les commande utilisé**
J'ai commencé par créer mon espace de travail?  a, avant d'ouvrir mon éditeur avec code .. Dans le script cantine.js, j'ai utilisé const et let pour les données, et Number() pour m'assurer que la quantité soit bien un chiffre.
